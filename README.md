# web-game-pilot

## 🕰️ 刻の女神と止まった世界

ブラウザで遊べる、選択肢分岐型のテキストアドベンチャーゲームです。

### 概要

事故で命を落とし、異世界アストラリアに転生した「あなた」。目覚めた世界は、花びらも雲も川の流れも、すべての時間が止まっていました。
始まりの時計塔で出会ったのは、力を失いかけた時の女神の少女・リーネ。
奪われた三つの「時の欠片」〈暁〉〈真昼〉〈黄昏〉を取り戻し、止まった世界の時間を動かすため、二人の旅が始まります。

- 全16シーン（本編13シーン＋エンディング3種）
- 選択によって **女神の好感度（💗）** と **フラグ** が変化し、文章・選択肢・結末が分岐します
- エンディングは TRUE / NORMAL / BAD の3種類
- 外部ライブラリ・画像・フォントは不使用（装飾は CSS と絵文字のみ）
- スマートフォンでも読みやすいレスポンシブレイアウト

### 遊び方

1. リポジトリ直下の `index.html` をブラウザで開きます（ダブルクリックで OK。ビルドやサーバーは不要です）。
   - ローカルサーバーで開く場合の例: `python3 -m http.server` を実行し、`http://localhost:8000/` にアクセス
2. タイトル画面で「▶ はじめから」を押すと物語が始まります。
3. 本文を読み、表示される選択肢をタップ（クリック）して物語を進めます。PC ではキーボードの数字キー `1`〜`9` でも選べます。
4. 画面上部のステータスバーで、集めた欠片（💎）と女神の心（💗ゲージ）を確認できます。
5. 「↺ 最初から」でいつでも最初からやり直せます。「🏠」でタイトルに戻れます。
6. 進行状況はブラウザに自動保存され、タイトル画面の「⏯ つづきから」で再開できます。見つけたエンディングもタイトル画面に記録されます。

> 💡 ヒント：すべての結末を見るには、リーネへの接し方や、旅の途中で知ったことが鍵になります。

### ファイル構成

```
index.html      … エントリーポイント（タイトル画面・ゲーム画面）
css/style.css   … スタイル（シーンごとの背景テーマ、レスポンシブ対応）
js/story.js     … シナリオデータ（シーン・選択肢・分岐条件）
js/game.js      … ゲームエンジン（状態管理・描画・セーブ）
```

シナリオを編集したい場合は `js/story.js` を変更してください。各シーンは本文・選択肢・効果（好感度／欠片／フラグ）・表示条件をデータとして持っています。

### 備考

- `file://` で直接開けるよう、ES Modules は使わず通常の `<script>` で読み込んでいます。
- セーブには `localStorage` を使用しています。プライベートブラウズなどで保存できない環境でも、ゲーム自体は最後まで遊べます。
