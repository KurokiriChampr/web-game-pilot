# web-game-pilot

## 🕰️ 刻の女神と止まった世界

ブラウザで遊べる、選択肢分岐型のテキストアドベンチャーゲームです。

**現在のバージョン：ver 3.0-p1**（ver 3.0 の Phase 1＝エンジン縦切り試作。タイトル画面の右下と、設定画面の下部に表示されます）

ver 3.0 Phase 1 の内容・検証結果・プレビュー方法は [`docs/v3-phase1-report.md`](docs/v3-phase1-report.md) を参照してください。

### 概要

事故で命を落とし、異世界アストラリアに転生した「あなた」。目覚めた世界は、花びらも雲も川の流れも、すべての時間が止まっていました。
始まりの時計塔で出会ったのは、力を失いかけた時の女神の少女・リーネ。
奪われた三つの「時の欠片」〈暁〉〈真昼〉〈黄昏〉を取り戻し、止まった世界の時間を動かすため、二人の旅が始まります。

- 全20シーン（本編13シーン＋寄り道3シーン＋エンディング4種）
- 選択によって **女神の好感度（💗）** と **フラグ** が変化し、文章・選択肢・結末が分岐します
- エンディングは TRUE / NORMAL / BAD / ANOTHER の4種類
- セーブ／ロード（オートセーブ＋手動 3 スロット）、バックログ、文字送りの速度設定
- ビジュアルノベル型の画面（全面背景・立ち絵・下部メッセージウィンドウ・中央の選択肢オーバーレイ）
- 背景画像・キャラクター立ち絵・BGM を後から差し込める設計（ファイルが無くてもグラデーション背景とテキストで動作）
- 外部ライブラリ・フォントは不使用。GitHub Pages にそのまま置ける静的サイト
- スマートフォン（縦・横）と PC の両方に対応したレスポンシブレイアウト

### 遊び方

1. GitHub Pages の URL、またはリポジトリ直下の `index.html` をブラウザで開きます（ビルド不要）。
   - `index.html` をダブルクリックで開いても遊べますが、その場合は画像と BGM が無効になります。
   - ローカルで画像と BGM も確認するときは `python3 -m http.server` を実行し、`http://localhost:8000/` を開きます。
2. タイトル画面で「はじめから」を押すと物語が始まります。
3. 本文は画面下部のメッセージウィンドウに、一段落ずつ、一文字ずつ表示されます。画面をタップ（または `Enter` / `Space`）すると、文字送り中なら全文が表示され、表示済みなら次の段落へ進みます（▼ が目印）。
4. シーンの本文を読み終えると、画面中央に選択肢が現れます。タップ、または PC では数字キー `1`〜`9` で選びます。
5. 一度読んだシーンでは、メッセージウィンドウ右上に「⏭ スキップ」が出て、選択肢まで飛ばせます。
6. 画面上部の HUD バーで、集めた欠片（💎）と女神の心（💗ゲージ）を確認できます。

| 操作 | ボタン | キー |
| --- | --- | --- |
| バックログ（これまでの本文と選んだ選択肢） | 📖 | `L` |
| BGM のミュート切り替え | 🔊 | `M` |
| セーブ | ☰ メニュー → 💾 セーブ | `S` |
| ロード・設定・背景を見る・最初から・タイトルへ | ☰ メニュー | – |

- **セーブ／ロード**：進行状況はシーンごとに自動保存され、タイトル画面の「⏯ つづきから」で再開できます。分岐の手前で手動スロット（3 つ）に保存しておくと、別の選択肢を試しやすくなります。
- **設定**：文字の表示速度（ゆっくり／ふつう／はやい／一瞬）、既読シーンの瞬間表示、BGM 音量、ミュート、背景画像の表示を切り替えられます。
- **記録**：見つけたエンディングと読んだシーンの数が、タイトル画面に表示されます。

> 💡 ヒント：すべての結末を見るには、リーネへの接し方や、旅の途中で知ったことが鍵になります。寄り道で手に入れたものは、あとで思わぬ場面の選択肢になります。四つ目の結末は、あなたが「時の流れ」をまだ信じきれていないときにだけ現れます。

### 画像と BGM の差し込み

`assets/images/` と `assets/bgm/` に決まった名前でファイルを置くだけで、シーンの背景画像（画面全体に表示）と BGM が付きます。対応は `assets/manifest.json` で定義しています。
シーンごとに `character` を足すと、キャラクター立ち絵も背景の上に重ねられます（任意）。
手順とファイル名の一覧は **[docs/ASSETS.md](docs/ASSETS.md)** を参照してください。

### ファイル構成

```
index.html            … エントリーポイント（タイトル・ゲーム画面・各ダイアログ）
css/style.css         … スタイル（VN レイアウト、テーマ、演出、レスポンシブ対応）
js/story.js           … シナリオデータ（シーン・選択肢・分岐条件・演出指定）
js/stage.js           … ページの正規化と舞台状態の計算（誰が・どのポーズ・どの表情・どの位置か）
js/assets.js          … 画像・立ち絵（複数枠）・光輪・BGM の管理（マニフェスト読み込み、フェード、音量）
tools/                … 検証スクリプト（本文不変の照合、舞台状態のテスト、ブラウザ自動確認、プレビュー用サーバ）
js/game.js            … ゲームエンジン（状態管理・文字送り・セーブ・バックログ・設定）
assets/manifest.json  … シーンIDと画像・立ち絵・BGM ファイルの対応表
assets/images/        … 背景画像・立ち絵の置き場所
assets/bgm/           … BGM の置き場所
docs/ASSETS.md        … 画像・立ち絵・BGM の差し込み手順
```

シナリオを編集したい場合は `js/story.js` を変更してください。各シーンは本文・選択肢・効果（好感度／欠片／フラグ）・表示条件をデータとして持っています。

### ver 2.1 の変更点（第2次アップグレード）

**バグ修正・堅牢化**

- クリア後の「タイトルへ」が反応しないことがある問題に対応しました。ボタン操作を `data-action` による一括受け付けに改め、画面の部品が 1 つ欠けても、ほかのボタン（もう一度はじめから／ロード／タイトルへ、メニュー内のタイトル遷移）が巻き添えで止まらないようにしました。タイトルへの遷移は、途中の処理で失敗しても最終的に必ずタイトル画面を出します。
- デプロイ直後の「古い `index.html` と新しい js の混在」を検出します。検出したら一度だけ自動で読み込み直し、それでも直らない場合は再読み込みの案内を表示します。
- `index.html` の css / js 参照にバージョンクエリ（`?v=2.1`）を付け、更新直後に古いファイルが使われにくくしました。
- タイトル画面と設定画面にバージョン表記（`ver 2.1`）を追加しました。

**ビジュアルノベル型の画面構成**

- 背景を画面全体に表示（画像が無いシーンはテーマ別グラデーション＋場面の紋章）
- 本文は画面下部の半透明グラデーションのメッセージウィンドウに、一段落ずつ表示。名前プレート欄には場面名を表示
- キャラクター立ち絵レイヤー（マニフェストの `character` / `characterPosition`。ファイルが無ければ何も出ません）
- 選択肢は画面中央のオーバーレイに表示（表示直後の誤タップ防止つき）
- シーン切替時に、シーンタイトルのバナーをシネマティックに表示
- 上部 HUD を細い半透明バーに集約（欠片・好感度・バックログ・サウンド・メニュー）
- タイトル画面を、キー画像フルブリード＋大きなタイトルロゴ＋メニューの構成に変更
- 既読シーンの「⏭ スキップ」ボタンを追加（設定の「一度読んだシーンは一瞬で表示する」も従来どおり使えます）

**互換性**

- シナリオ（`js/story.js`：20 シーン／エンディング 4 種／分岐条件）は変更していません。
- `localStorage` のキーと保存形式は変更していません。以前のオートセーブ・手動スロット・既読・エンディング記録・設定は、そのまま引き継がれます。
- 既存の `assets/manifest.json` はそのまま使えます（`character` は任意の追加項目です）。

**バージョンを上げるとき**

`index.html` の `data-app-version` と 5 か所の `?v=`、`js/game.js` の `VERSION` を同じ値にそろえてください。

### 第1次アップグレードの変更点

**遊びごたえ**

- 寄り道シーンを 3 つ追加：「焼きたての朝」（村）、「渡し守の舟」（大河）、「刻告げの歌」（星空）。いずれも既存の選択肢を残したまま、新しい選択肢から入れます。
- 寄り道で得たものが後の場面に効きます（焚き火でパンを分ける、時喰いの王にオルゴールを聴かせる、など）。エンディングの文章にも反映されます。
- 四つ目の結末 ANOTHER END「永遠の一秒」を追加。
- 既存シーンの文章は変更していません。追加は「新しい選択肢」と「条件付きで差し込まれる段落」のみです。TRUE END の条件も従来のままです。

**機能**

- 文字送り（速度 4 段階、タップで全文表示、既読シーンの瞬間表示）
- セーブ／ロード（オートセーブ＋手動 3 スロット、上書き確認と削除つき）
- バックログ（本文と選んだ選択肢。セーブデータと一緒に保存されます）
- 設定画面（文字速度・BGM 音量・ミュート・背景画像の表示・記録の消去）
- タイトル画面の強化（文字盤の紋章、宙に留まる花びら、ロード／設定、読んだシーン数）
- シーン演出（場面転換のフェード、宙に留まる花びら・森の光・焚き火の火の粉・埃、揺れ、閃光、欠片入手の通知、好感度ゲージの反応）
- 画像・BGM の差し込み（背景画像、背景鑑賞モード、シーン単位のループ再生とフェード）

**互換性**

- 旧バージョンのオートセーブと、見つけたエンディングの記録はそのまま引き継がれます。

### 備考

- `file://` で直接開けるよう、ES Modules は使わず通常の `<script>` で読み込んでいます。
- セーブ・設定・記録には `localStorage` を使用しています（ブラウザごと・端末ごとに別々です）。プライベートブラウズなどで保存できない環境でも、ゲーム自体は最後まで遊べます。
- 「動きを減らす」設定（`prefers-reduced-motion`）が有効な環境では、演出を抑え、文字は既定で一瞬表示になります。
