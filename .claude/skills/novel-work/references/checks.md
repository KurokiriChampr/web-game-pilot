# 点検 `tools/validate-story.js` の読み方と直し方

```sh
node tools/validate-story.js --work works/<作品ID>            # 点検
node tools/validate-story.js --work works/<作品ID> --strict   # 注意も失敗にする（公開前の最終確認に）
node tools/validate-story.js --work works/<作品ID> --quiet    # 注意を個別に出さない
```

- 1 行目：シーン数（到達できる数）・章・ページ・字数・選択肢・結末・同時に並ぶ立ち絵の最大。2 行目：既読データの見積もり。
- 最後の行 `OK: 誤り 0 件、注意 n 件` が関門。**誤り**は終了コード 1（動かない・壊れる）、**注意**は 0（動くが意図を確かめる）。
- 関数の本文・選択肢・`next` は、見ているフラグを「全部なし／全部あり／1 つずつ」、好感度・欠片を下限・0・上限、変数を 1 つずつ振って試す。
  **組合せでだけ起きる問題は見つけられない**ので、分岐の多い関数はプレビューでも通しておく。
- 規則の正本はツールの冒頭のコメント。ここに無い文言が出たら、ツールのコードを読む。

## 誤り

| 出る文言（要旨） | 直し方 |
| --- | --- |
| `js/work.js：id … がありません` | `WORK.id` を書く（英小文字・数字・ハイフン） |
| `STORY.start：開始シーン … がありません` | `start` を実在するシーン ID に |
| `行き先のシーン … がありません` | 選択肢・`next` の行き先の綴り、関数の返り値を確かめる |
| `選択肢も next もありません` | 結末にするなら `ending`、続くなら `choices` か `next` |
| `next だけで輪になっていて抜けられません` | 輪のどこかに選択肢を置くか、関数の `next` で抜け道を作る |
| `話者 … が STORY.cast にありません` | `cast` に足すか、`speaker` の綴りを直す |
| `人物／ポーズ／表情 … が manifest にありません` | manifest の `characters` に足すか、story の綴りを直す。初登場で `pose`／`expr` を省くと `stand`／`normal` になるので、manifest にそれが無い人物に注意 |
| `背景／一枚絵 … が manifest の backgrounds にありません` | manifest の `backgrounds` に足す |
| `知らない項目 …` | 項目名の綴り（`story-format.md` の表にある名前だけ使える） |
| `pos の値 … は使えません` | `left`／`center`／`right` |
| `シーン ID に # と > は使えません` | ID を変える（`_` や `-` を使う） |
| `title がありません`／`text がありません`／`本文が空です` | シーン名・本文を書く |
| `text の関数が例外を出しました` | 関数の中で `s.flags.x.y` のように未定義をたどっていないか |
| `結末 ID … が重複しています` | `ending.id` を作品の中で一意に |
| `章 … が STORY.chapters にありません` | `chapters` に足すか、`chapter` の綴りを直す |
| `変数 … は STORY.vars で宣言されていません`／`per に人物 … がありません` | `vars` に宣言を足すか、綴りを直す |
| `… の更新は数値（加算）か { set: 数値 }（代入）にしてください` | `effects.vars` の値の形を直す |
| 変数の宣言の書式（変数名・`min`＞`max`・初期値が範囲外・`per` の形） | `story-format.md`「変数」 |
| `STORY.unlocks.… ：エンディング ID … の結末がありません` | `ending.id` の綴り（シーン ID ではなく結末の ID） |
| 解放の宣言の書式（フラグ名・`endings` の形・重複・`count` の範囲） | `story-format.md`「周回をまたぐ解放」 |

## 注意

| 出る文言（要旨） | 確かめること |
| --- | --- |
| `退場の指定（hide）なしに押し出されました` | 意図どおりか。違うなら、先に `hide` するか空いている `pos` へ |
| `同じ本文のページが 2 つあります` | 既読を共有してしまう。文言を少し変える |
| `開始シーンからたどり着けません` | 行き先の書き忘れ。下書きのシーンなら消す |
| `endingCount … ですが、結末のシーンは … 個` | `endingCount` を結末のシーンの数に合わせる |
| `css に body.theme-… がありません` | `css/work.css` にテーマを足す |
| `すべての選択肢に requires があります` | 全部隠れたときの行き先として `next` を足す |
| `結末のシーンに選択肢／next があります` | 使われないので消す |
| `next だけの輪です。行き先の関数しだいで抜けられます` | 抜ける条件が必ず満たせるか |
| `per の … は manifest にも cast にもありません` | 人物 ID の綴り |
| `フラグ … を読む関数（requires・next・text）がありません` | 解放したフラグを `requires` などで使っているか、綴り |
| `フラグ … を effects・onEnter でも立てています` | 周回の解放と、その周の中での成立を同じフラグにしてよいか |
| `フラグ … が立っていない周では、条件のエンディングのうち … 個にしか届きません` | 解放の条件に、そのフラグで開く結末を入れていないか |
| `知らない演出 fx` | `hop`／`shake`／`flash` のどれか |
| `show に n 人います` | 同時に並ぶのは 3 人まで |
