- 欠片の声（ruins の『時が流れれば…』と、その前置き「近づくと、欠片から厳かな声が響いた。」）
- 時喰いの影の台詞（boss「来ないで」、sacrifice reached「……独りじゃ、ないの？」、end_still「……ほんとうに？」）

## 3. 判断に迷った点

| # | 内容 | 採った対応 |
| --- | --- | --- |
| 1 | **立ち絵が舞台にいないリーネの台詞 4 段落**：village selfish「「時が戻れば、…」そう答えたきり…」、end_true「「うそ……力が、半分ずつ……？」」、end_true bakeryPromise「「約束、覚えてる？」…」、end_bad「「……どうして、もっと」遠くでリーネの声がした気がした。…」 | **付けていない**。`tools/test-stage.js` が「`speaker` のあるページでは話者の立ち絵が舞台にいること」を全展開で検査しており、付けると NG になる。立ち絵を足すと `chara` の追加になり、今回の「足すのは speaker だけ」の範囲を超える。名前札だけ出したい場合は、test-stage.js のその検査を緩めて 1 行ずつ `speaker` を足せば済む。立ち絵ごと出す場合は、舞台指示の追加として別途指示がほしい |
| 2 | **文字列段落 3 つのオブジェクト化**（forest／river／sacrifice） | `speaker` を付けるために `{ text, speaker }` の形にした。表示テキスト列は verify-text.js で基準と一致することを確認した。`speaker` だけのページでは立ち絵・表情・光輪は変わらない（`stageAt` は chara／pose／expr／pos が無ければ立ち絵を触らない）。test-stage.js の舞台遷移の照合（`trace`）も修正前と同じ値で合格 |
| 3 | **既存の chara は残した** | explain は `speaker` だけで立ち絵を指していたが、Phase 2 の段落は `chara: "rine"` で舞台を指定済み。今回はその前に `speaker` を足すだけにした。chara が優先されるので、見た目は修正前と同じ |
