# 画像・立ち絵・BGM の差し込み手順

『刻の女神と止まった世界』は、**ファイルを置くだけ**で背景画像・キャラクター立ち絵・BGM が付くようになっています。
ファイルが無いあいだは、テーマ別のグラデーション背景とテキストで動き、エラーで止まることはありません。

画面はビジュアルノベル型です。背景画像は**画面全体**に表示され、その上に立ち絵、いちばん下に半透明のメッセージウィンドウが重なります（ver 2.1〜）。

## 1. いちばん簡単な手順

1. 画像を `assets/images/` に、BGM を `assets/bgm/` に、下の表のファイル名で置く
2. コミットして push する（GitHub Pages に反映されれば完了）

`assets/manifest.json` には、全シーンぶんの推奨ファイル名があらかじめ書いてあります。
**表のファイル名どおりに置くなら、マニフェストの編集は不要です。** 一部のシーンだけ先に置いても構いません（無いシーンはテキストのみになります）。

## 2. マニフェストの書き方（`assets/manifest.json`）

```json
{
  "version": 1,
  "basePath": "assets/",
  "defaults": { "image": null, "bgm": null },
  "title": { "image": "images/title.jpg", "bgm": "bgm/title.mp3" },
  "scenes": {
    "awakening": { "image": "images/awakening.jpg", "bgm": "bgm/field.mp3" }
  }
}
```

| キー | 内容 |
| --- | --- |
| `basePath` | ファイルパスの基準フォルダ。通常は `assets/` のまま |
| `defaults` | シーン側に項目が無いときに使う既定値 |
| `title` | タイトル画面の画像と BGM |
| `scenes` | シーンID（`js/story.js` の `scenes` のキー）ごとの設定 |

各シーンに書ける項目：

| 項目 | 値 | 説明 |
| --- | --- | --- |
| `image` | 文字列 / 配列 / `null` | 背景画像（画面全体に表示）。`null` は「このシーンでは画像なし」 |
| `character` | 文字列 / 配列 / `null`（省略可） | キャラクター立ち絵。背景の上に表示する。省略・`null`・ファイル無しのときは何も出さない |
| `characterPosition` | `"left"` / `"center"` / `"right"`（省略可） | 立ち絵の横位置。省略時は `"center"` |
| `bgm` | 文字列 / 配列 / `null` | BGM。`null` は「このシーンでは無音」 |
| `position` | 文字列（省略可） | 背景画像の見せる位置。CSS の `background-position` と同じ書き方（例 `"center top"`） |
| `volume` | 0〜1 の数値（省略可） | その曲だけ音量を下げたいときの倍率（例 `0.7`） |

- **拡張子が違う場合**は、マニフェスト側のファイル名を書き換えてください（例 `"images/forest.webp"`）。
- **配列**で書くと、先頭から順に試し、最初に読み込めたものを使います。
  例：`"image": ["images/forest.webp", "images/forest.jpg"]`
- 項目そのものを省略すると `defaults` の値が使われます。全シーン共通の BGM を流したいときは `defaults.bgm` に書きます。
- JSON なので、コメントは書けません。最後の項目のあとにカンマを付けないよう注意してください。

## 3. 素材の目安

| 種類 | 形式 | 目安 |
| --- | --- | --- |
| 画像 | JPEG / WebP / PNG | 横長 16:9、1600×900 px 前後、1 枚 300KB 以下だと読み込みが軽い |
| BGM | MP3（推奨）/ M4A / OGG | ループを前提にした曲。1 曲 1〜3MB 程度。OGG は iPhone の Safari で再生できないため MP3 が無難 |

- 背景画像は画面全体に `cover` で表示されます（はみ出した部分は切れます）。PC では横長、スマホ縦持ちでは中央の縦長部分だけが見えるので、主題は中央寄りに置いてください。見せたい位置がずれるときは `position` で調整できます。
- 画面の下 3〜4 割にはメッセージウィンドウ（下に向かって濃くなる半透明のグラデーション）が重なります。大事なものは画面の上〜中央に置くのがおすすめです。
- 上端には細い HUD バー（約 44px）が重なります。
- BGM はファイルの頭と末尾がそのままつながります。無音の余白が入っていると、ループのたびに間が空きます。

## 4. キャラクター立ち絵

シーンごとに、任意で立ち絵を 1 枚重ねられます。マニフェストのシーンに `character` を足すだけです。

```json
"scenes": {
  "meet": {
    "image": "images/meet.jpg",
    "bgm": "bgm/tower.mp3",
    "character": "images/chara/rine_normal.png",
    "characterPosition": "right"
  }
}
```

- **既定では、どのシーンにも `character` は書いてありません**（立ち絵なしで動きます）。使いたいシーンにだけ足してください。
- ファイルの置き場所は自由です（例：`assets/images/chara/`）。パスは `image` と同じく `basePath`（`assets/`）からの相対で書きます。
- `image` と同じく、配列で候補を並べられます。ファイルが無い・読み込めないときは**何も表示せず**、ゲームはそのまま続きます。
- **素材の目安**：背景が透過した PNG / WebP。縦長（幅 1：高さ 2 前後）、高さ 1600px 前後。画像の**下端が画面の下端**にそろい、高さは画面の約 9 割で表示されます。膝〜腰から下はメッセージウィンドウに隠れるので、顔と上半身が画像の上半分に来るように作ると収まりがよくなります。
- 次のシーンも同じファイルなら、そのまま表示し続けます。違うファイルならフェードで入れ替わり、`character` の無いシーンに入ると消えます。
- 選択肢が出ているあいだは、立ち絵が少し暗くなります。
- 「⚙ 設定」の「背景画像・立ち絵を表示する」をオフにすると、背景画像と一緒に立ち絵も非表示になります。
- 全シーン共通で出したい場合は `defaults.character` に書けます（特定のシーンだけ消すときは、そのシーンに `"character": null`）。

## 5. 動作のしくみ

- 画像：シーンに入るたびに切り替わります（クロスフェード）。メニューの「🖼 背景を見る」で、HUD とメッセージウィンドウを隠して、背景と立ち絵だけを見られます（タップ、または `Esc` で戻ります）。
- 画像が無いシーン：テーマ別のグラデーション背景と、場面を表す紋章（絵文字）が表示されます。
- BGM：シーン単位でループ再生します。**次のシーンが同じ曲なら、頭出しせずにそのまま流れ続けます。** 曲が変わるときはフェードで切り替わります。
- 音量とミュートは「⚙ 設定」、または画面上部の 🔊 ボタン（キーボードは `M`）で変えられ、ブラウザに記憶されます。
- ブラウザの自動再生制限により、BGM は**最初のタップ／キー操作のあと**に鳴りはじめます（タイトル画面を開いた直後は無音です）。
- タブを裏に回すと BGM は一時停止し、戻ると再開します。
- iPhone / iPad は OS の仕様で、ページ側から音量を変えられません（ミュートは効きます）。音量は本体のボタンで調整してください。

### ファイルが無いとき

| 状況 | 動作 |
| --- | --- |
| マニフェストに書いたファイルが無い | その画像／立ち絵／曲だけを飛ばして続行（背景はテーマ別グラデーション） |
| `assets/manifest.json` 自体が無い・壊れている | 画像・立ち絵・BGM なしで続行 |
| `index.html` をダブルクリックで開いた（`file://`） | ブラウザの制限でマニフェストを読めないため、画像・立ち絵・BGM なしで続行 |

ファイルが無いあいだは、ブラウザの開発者ツールに `404` の読み込み記録が出ますが、これは「まだ置かれていない」という記録で、ゲームの動作には影響しません。同じファイルを取りに行くのは、ページを開いてから 1 回だけです。

## 6. 確認のしかた

画像と BGM は `file://` では確認できません。ローカルで試すときは簡易サーバーを使ってください。

```
python3 -m http.server
```

`http://localhost:8000/` を開き、「⚙ 設定」を開くと、いまの場面に画像と BGM が適用されているかが表示されます（「この場面：背景画像 あり ／ 立ち絵 なし ／ BGM あり」）。

反映されないときは、次の順に確認してください。

1. ファイル名と拡張子が、マニフェストの記述と大文字・小文字まで一致しているか（GitHub Pages は区別します）
2. `assets/manifest.json` が正しい JSON か（カンマの付け忘れ・付けすぎ）
3. 設定の「背景画像・立ち絵を表示する」がオンで、ミュートがオフか
4. ブラウザのキャッシュ（スーパーリロードで再読み込み）

## 7. シーンを追加したとき

`js/story.js` に新しいシーンを足したら、同じ ID で `assets/manifest.json` の `scenes` に 1 行追加します。追加しなくても、そのシーンは `defaults` の設定（既定ではテキストのみ）で動きます。
