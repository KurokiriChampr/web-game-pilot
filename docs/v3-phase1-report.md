## 3. 設計判断

### 3-1. データ形式（研究文書 §A-3 の①混在配列）

- `text` の要素は「文字列」または「`{ text, speaker, chara, pose, expr, pos, show, hide, bg, cg, halo, fx }`」。文字列は `{ text }` に包むだけで、本文には触れない。
- 立ち絵の状態は**持ち越す**（変更か `hide` があるまで続く）。話者と `fx` はそのページだけ。光輪 `halo`・背景 `bg` は持ち越す。
- `speaker` があり `chara` が無ければ、`cast[speaker].chara` の立ち絵に表情を適用する（`girl` → `rine`）。
- 新しい人物の既定値は `pose: "stand"`／`expr: "normal"`／`pos: "center"`、光輪の既定は `"weak"`。
- 表情の論理名のうち、研究文書に例が無い「苦笑」「真剣」は `wry`／`serious` と名付けた（要確認 → §6）。

`meet`／`explain` に付けた指定：

| シーン | ページ | 話者 | 立ち絵 | 光輪 | 演出 |
| --- | --- | --- | --- | --- | --- |
| `meet` | （petal 時のみ）指先が触れた瞬間… | — | なし（登場前） | — | — |
| | 時計塔の足元。… | — | `sit`／`down`／中央 | weak | — |
| | 淡い金色の髪。… | — | `sit`／`down` | weak | — |
| | この止まった世界で… | — | `sit`／`down` | weak | — |
| | 少女はゆっくり顔を上げ… | 少女 | `sit`／`surprised` | weak | `hop` |
| `explain` | 「私はリーネ。… | リーネ | `stand`／`normal`／中央 | weak | — |
| | 少女は苦笑して… | リーネ | `stand`／`wry` | weak | — |

両シーンとも `stage: { bg: "tower_foot", halo: "weak" }`（同じ背景を共用。研究文書 §B-3 の「同じ場所なのに絵が連続しない組」への対処）。

### 3-2. 状態再現（`stageAt`）

- `stageAt(pages, index, { stage, cast })` は、`scene.stage` を初期値に 0 ページ目から `index` まで畳み込む純関数。`index < 0` はシーン開始位置。
- エンジンは「前のページからの差分」を持たず、**ページを表示するたびに `stageAt` を呼び直す**。そのため 1 ページずつ進めても、既読スキップで最終ページへ飛んでも、ロード直後でも、バックログを開閉しても、同じ結果になる（研究文書 §A-2 #5 への対処）。
- セーブデータにページ位置や立ち絵の情報は**足していない**。再開は v2.1 と同じくシーン先頭からで、状態は本文データから再計算する。
- シーンに入った時点で、そのシーンで使う立ち絵を先読みする（§A-2 #4）。

### 3-3. セーブ互換（§A-4）

- `state.log` の `paras` は**文字列の配列のまま**。話者名は、話者のいるシーンだけ同じ長さの別配列 `who` に入れる（旧版は無視する）。
- セーブの項目は `{scene, affection, shards, flags, steps, log}` のまま。キー 5 件・シーン ID・フラグ名・エンディング ID は無変更。
- 設定キーに項目は足していない。

### 3-4. 表示

- **立ち絵**：`#char-layer` の中に、人物ごとの枠 `.chara[data-id][data-pos]` を出し入れする。枠の中は下から「光輪 → 体」。v2.1 のシーン単位 `character` 指定（`docs/ASSETS.md` §4）も同じ枠の仕組みで引き続き動く。
- **縦画面**（幅 560px 以下の縦）：1 人なら常に中央、2 人以上なら 75% に縮めて 32%／68%（§A-6）。2 人表示は `stageAt` とレイアウトまで実装済みだが、`meet`／`explain` は 1 人なので画面では未使用。
- **話者強調**：話者以外は明るさ 60%。地の文では全員ふつうの明るさ（§A-6）。
- **名前札**：話者名を `#speaker-name` に出し、色は `cast[x].color` を `--speaker` で渡す（濃紺地に #f2d48a）。シーン名の `<h2>`（フォーカス先・読み上げ用）は残し、見た目だけ隠す。
- **光輪**：画像ではなく SVG（欠けのある二重の円環＋目盛り＋ひび）。立ち絵の枠に対する % で置くので、画面サイズが変わっても立ち絵に追随する。位置はポーズごとにマニフェストの `halo: { x, y, size }`。状態は `weak`／`flicker`／`bright`／`off`。`prefers-reduced-motion` では明滅を止めて弱い発光の静止にする。**見た目は仮**。
- **背景**：`stage.bg` の論理名 → `manifest.backgrounds`。無い・読めないときは `scenes[id].image`（従来の 1 枚絵）へ戻る。焦点は CSS 変数で渡し、縦長の画面では `positionPortrait` を優先する。
- **素材欠落時**：表情のファイルが無ければ、その人物の枠ごと出さない（別の表情で代用はしない）。光輪も枠と一緒に出ない。
