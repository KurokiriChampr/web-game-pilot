## 2. 実装内容

### 作業 1：段落の `bg`
- `stageAt` は Phase 1 から `bg` を畳み込んでいたので、状態計算は既存のまま。表示側は、論理名が変わると背景候補の先頭が変わり、既存の 2 枚重ねレイヤーでクロスフェード（0.9 秒）する。
- 追加したのは先読みだけ。シーン開始時に、そのシーンで使う背景（`stage.bg` と段落の `bg`）を読み込んでおく。
- ファイルが無い論理名は従来どおり `scenes[id].image` へ戻る。

### 作業 2：段落 `fx` の `shake`／`flash`
- どちらも CSS アニメーション。`shake` は `body.is-shaking` で、ウィンドウ・立ち絵・背景を 0.6 秒揺らす（背景は 3% 拡大して端を見せない）。`flash` は既存の `#flash`（白、1 秒で消える）。
- Phase 1 報告の持ち越し「画面シェイクが背景・立ち絵に掛からない」は、ここで解消した。
- 無効化は二重にしてある。JS は「設定の演出オフ」または `prefers-reduced-motion` のとき呼ばない。CSS も同じ条件で `animation: none`。`hop` も同じ扱い。
- 演出オフでも、立ち絵・光輪の状態・背景の切替は変わらない（物語の情報なので残す）。

### 作業 3：シーンの `enter`
- **実装済みだった**（v2.1 からある `playEnterEffect`）。boss＝shake、sacrifice＝flash、end_true＝flash が実行されることをブラウザで確認した。
- 段落 `fx` と同じ関数を通すように変えたので、演出オフ・reduced-motion でも同じく止まる。

### 作業 4：光輪 `strong`／`off`
- `strong`：不透明度 1、二重の発光、ゆっくりした脈動。`off`：不透明度 0（Phase 1 から存在）。
- 継続と既定値（明示まで継続・初登場時は weak）は Phase 1 の `stageAt` の動作そのまま。単体テストで固定した。

### 舞台割り当て（18 シーン）
指示書どおり。位置はすべて center。各ページの状態は `tools/test-stage.js` の末尾に期待値として書いてあり、指示書と突き合わせられる。判断が入った箇所は §4。

## 4. 判断に迷った点

| # | 内容 | 採った対応 |
| --- | --- | --- |
| 1 | **`speaker` を足すか**。追加してよい項目に `speaker` が無い | 足していない。その結果、18 シーンの台詞ページでは名前札が出ず（地の文扱い）、シーン名は「第 n 幕」の横に出る。meet／explain だけ名前札が出る状態。全台詞に付けるなら別途指示がほしい |
| 2 | **「設定の演出オフ」が存在しなかった** | 設定画面に「画面の揺れ・フラッシュの演出を表示する」（既定オン）を追加した。保存先は既存の設定キーの中の `effects` 項目で、キーは増やしていない。旧版はこの項目を無視する。不要なら UI だけ外せる |
| 3 | **分岐の導入段落が無いルートでの立ち絵**（forest の kindness なし、river の shared なし、ruins の asked／lore なし）。指示は「2 段落目は normal」のように導入段落がある前提の数え方 | 段落の**内容**に付けた。forest は「欠片の描写」、river は「翌朝――」、ruins は「砂に埋もれた…」の段落に `stand normal` を明示したので、導入が無いルートではその段落で登場する。導入なしのルートでは出さない方がよければ、その 3 段落から `chara` を外すだけで変えられる |
| 4 | **ruins の `normal` に戻す位置**。「以後の欠片の声の段落でも表示は継続（expr normal）」 | 共通部分の最初の段落（神殿の描写）で normal にした。asked ルートは「sad → 次のページで normal」になる |
| 5 | **sacrifice の「最後の 2 段落」**。括弧書きの「手を添える／台詞」は実際には最後の 1 段落に両方入っている | 文字どおり最後の 2 段落（「三つの欠片が…」「『最後は、私の番』…」）を `strong` にした。最後の 1 段落だけにするなら 1 行消すだけ |
| 6 | **光輪 `bright`**。Phase 1 に同じ意味の `bright` が既にあった | `strong` を正式名として追加し、`bright` は同じ見た目の旧名として残した（シナリオでは未使用） |
| 7 | **検証ツール自体の変更**。`verify-text.js` と `test-stage.js` は「meet／explain 以外は従来形式」を検査しており、Phase 2 の作業そのものが NG になる | 範囲チェックだけを Phase 2 用に置き換えた。本文・選択肢・属性の照合と基準データ（`tools/baseline/`）には触れていない |
| 8 | **campfire の else 分岐** | 本文の分岐は `brave`／`clever`／それ以外。「それ以外」に relied の指定（eyes_closed）を付けた |
| 9 | **night の花びら段落**（petal 時のみ、最後の台詞の後ろ） | 「全段落 sit down」に従い sit down。光輪は直前の flicker が継続する |
